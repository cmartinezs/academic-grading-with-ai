# Onboarding Workspace

Este directorio contiene una simulación guiada para practicar el flujo completo del workspace sin tocar ninguna sección real.

La práctica usa una sección ficticia:

```text
ONB1001-001V
```

El objetivo es que el profesor practique el proceso real paso a paso, trabajando con el agente como lo haría en una evaluación normal:

1. Inicializar una asignatura/sección.
2. Importar el roster.
3. Crear una evaluación.
4. Cargar enunciados y rúbricas.
5. Pedir al agente que actualice `base.md`, `case.md` y `plan.md`.
6. Asignar formas.
7. Simular una descarga de entregas desde AVA.
8. Extraer y revisar estructura.
9. Ejecutar una marcha blanca de corrección.
10. Registrar consideraciones adicionales si hace falta.
11. Corregir por bloques.
12. Exportar resultados.

Empieza por:

```text
onboarding/guide.md
```

Los archivos bajo `onboarding/data/` son insumos de práctica. No representan estudiantes reales.
