# Enunciado Forma D

## Ejercicio 1: Despacho de pedidos

Una tienda necesita validar si puede despachar un pedido.

El programa debe:

1. Mostrar un mensaje de inicio.
2. Solicitar el saldo disponible del cliente.
3. Solicitar el monto total de la compra.
4. Si el saldo alcanza, mostrar `Pedido aprobado` y el saldo restante.
5. Si el saldo no alcanza, mostrar `Pedido rechazado`.
6. Finalizar con el mensaje `Fin del proceso`.

## Ejercicio 2: Registro de gastos diarios

Una persona desea registrar gastos del día.

El programa debe:

1. Mostrar un menú repetitivo con las opciones:
   - `1. Registrar gasto`
   - `2. Ver total`
   - `3. Salir`
2. Acumular los gastos ingresados.
3. Validar que cada gasto sea mayor que cero.
4. Mostrar el total cuando el usuario elija la opción 2.
5. Terminar cuando el usuario elija la opción 3.
