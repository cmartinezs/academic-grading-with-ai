# ADR-0002 — Config de sección enriquecido y versionado

- Estado: Propuesto
- Fecha: 2026-08-01

## Contexto

El base ya genera `evaluations/<SECTION>/config.json` vía `init-course.sh`, pero con
schema mínimo (course + evaluations{}). El ref demuestra la utilidad de metadata
completa por sección (forms, pesos, fechas, tipos, access).

## Decisión

Enriquecer `config.json` de sección con `schemaVersion`, `access` (docente/director/
estudiante) y evaluación con forms/pesos/fechas/tipos, validado contra
`section-config.schema.json`.

## Consecuencias

- La realidad de cada curso vive en datos, no en código.
- La metadata alimenta a los publishers (portal, email, BI) sin hardcodear secciones.
- Compatibilidad: schemaVersion permite evolucionar sin romper secciones existentes.
