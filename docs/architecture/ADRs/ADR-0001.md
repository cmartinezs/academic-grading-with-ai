# ADR-0001 — Fuente canónica de resultados: results.json

- Estado: Propuesto
- Fecha: 2026-08-01

## Contexto

Los resultados existen como `results/*.md` (evidencia humana) y el ref re-parsea `.md`
en cada paso (incluido el export 3FN), duplicando lógica y arriesgando divergencias.

## Decisión

`exports/publication-input/course/results.json` es la **fuente canónica máquina**.
Único responsable de parsear `.md`: `export-publication-data.py`. Todos los publishers
leen de `results.json`.

## Consecuencias

- Parsing centralizado y validado contra `results.schema.json`.
- Publisher 3FN del ref se adapta para leer `results.json` (no `.md`).
- `.md` queda como evidencia revisada, no como input de derivación.
