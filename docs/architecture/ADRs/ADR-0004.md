# ADR-0004 — Reglas de calificación declarativas (grade-rules.json)

- Estado: Propuesto
- Fecha: 2026-08-01

## Contexto

Las reglas del ref (pesos EV, `presentation-weighted-average`, `pct-distribute-to-
presentation`, `evg-bonus-or-replacement`, cap de bonus, redondeo) están hardcodeadas
en `export-relational-3fn.py:733-781`. Cada docente tiene reglas distintas.

## Decisión

Las reglas de calificación se expresan de forma **declarativa** en `grade-rules.json`
por sección/evaluación, interpretadas por un engine genérico en el core.

```json
{
  "rules": [
    {"id": "presentation-weighted-average", "weights": {"EV1": 0.20, "EV2": 0.25, "EV3": 0.30, "EV4": 0.25}},
    {"id": "missing-as-min-grade", "applyIf": "component missing"},
    {"id": "bonus", "source": "PCT", "cap": 7.0, "mode": "sum-to-presentation"},
    {"id": "replacement", "source": "EvG", "when": "level>=4", "target": "worst-presentation"}
  ]
}
```

## Consecuencias

- Determinismo por datos; un docente cambia pesos sin tocar código.
- El motor es genérico y escalable a cualquier asignatura/evaluación.
- La capa `discovery` (ADR-0010) genera borradores de `grade-rules.json` revisables.
