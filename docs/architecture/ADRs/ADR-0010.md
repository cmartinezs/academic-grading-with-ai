# ADR-0010 — Capa de descubrimiento separada, con aprobación humana

- Estado: Propuesto
- Fecha: 2026-08-01

## Contexto

El workspace debe automatizar de forma determinista lo que naturalmente lo es, y ser
capaz de descubrir (no determinista) configuraciones útiles para cada docente y sus
evaluaciones particulares.

## Decisión

Capa `discovery/` opcional, NO determinista (LLM), que a partir del material crudo de
un docente (brief, rúbrica, muestras) emite una **config candidata**: `grade-rules.json`,
forms, schemas, patrones de parsing. La salida es un borrador que **requiere aprobación
humana** antes de entrar al pipeline determinista.

## Consecuencias

- El core nunca mezcla lógica no determinista con lógica determinista.
- El borrador aprobado se convierte en config determinista (ADR-0002, ADR-0004).
- Escalable a cualquier docente/asignatura sin tocar código.
