# ADR-0005 — Node.js opcional, solo en publishers

- Estado: Propuesto
- Fecha: 2026-08-01

## Contexto

El core es Python. Los publishers de email (nodemailer) y portal (SPA builder) del ref
son Node.js y ya están probados.

## Decisión

Node se usa **solo** en los publishers email y portal, reutilizando el código del ref
(versiones pinneadas). Cada wrapper verifica disponibilidad del runtime y falla con
mensaje claro; la ausencia de Node no rompe el core ni los publishers Python.

## Consecuencias

- Costo cero de reescritura; menor mantenimiento al no reimplementar.
- Dependencia de runtime opcional, documentada en cada wrapper.
- Si algún día se desea, se puede reescribir en Python sin cambiar contratos.
