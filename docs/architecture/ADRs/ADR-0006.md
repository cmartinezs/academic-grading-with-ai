# ADR-0006 — Versionamiento, validación y alcance del determinismo

- Estado: Aprobado
- Fecha: 2026-08-01
- Fecha de aprobación: 2026-08-01

## Contexto

El diseño anterior exigía determinismo byte a byte para todo publisher. Esa afirmación es
incompatible con timestamps, claves aleatorias, cifrado, message IDs, reintentos y estado
de entrega. Además, JSON Schema por sí solo no valida invariantes académicos.

## Decisión

### Versionamiento

Todo contrato declara SemVer:

- patch: corrección sin cambio de contrato;
- minor: adición retrocompatible;
- major: cambio incompatible con migración explícita.

El Publication Snapshot registra las versiones exactas de schemas, parser, policy engine
y publishers relevantes.

### Validación

Cada gate combina:

1. validación sintáctica por schema;
2. validación referencial;
3. invariantes semánticos;
4. validación de privacidad por audiencia;
5. compatibilidad de versiones.

El pipeline falla cerrado.

### Determinismo

Los **builders puros** deben cumplir:

```text
mismo input lógico + mismas versiones + mismo entorno normalizado
→ mismo output lógico
```

Cuando se requiera comparación byte a byte, metadata volátil se separa o se fija mediante
un clock inyectable/`SOURCE_DATE_EPOCH`.

Los **executors con efectos** no son deterministas. Deben ser:

- idempotentes;
- auditables;
- reanudables;
- protegidos por locks;
- capaces de detectar payload drift.

## Alternativas consideradas

### Solo JSON Schema

Rechazada: no detecta pesos inválidos, referencias rotas, PII o conflictos de policy.

### Determinismo universal

Rechazada: formula una garantía imposible para operaciones externas.

### Determinismo por capa

Aceptada: propiedades correctas según el tipo de componente.

## Consecuencias

- `generatedAt` no participa en el contenido lógico determinista o usa clock controlado.
- Cifrado y SMTP se prueban por propiedades, idempotencia y contratos, no por golden bytes.
- Cada migración major debe ser explícita y trazable.
- Los validators se convierten en componentes de dominio, no simples wrappers de schema.
