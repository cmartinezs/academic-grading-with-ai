# ADR-0003 — 3FN como modelo de información derivado (3 audiencias)

- Estado: Propuesto
- Fecha: 2026-08-01

## Contexto

El export relacional 3FN del ref (25 tablas + vistas) debe incorporarse, pero no como
fuente. Se define por consumidor: estudiantes (portal), docente (análisis) y directiva
institucional (BI).

## Decisión

El 3FN es un **modelo de información derivado** de `results.json`, con tres capas:
tablas transaccionales (uso interno), vistas de consulta (docente), vista estudiante
(portal) y vistas BI (directiva, solo agregados). Regla anti-fuga: celdas n < umbral
se suprimen en capas BI.

## Consecuencias

- La canónica sigue siendo `results.json`; el 3FN se regenera por demanda.
- Schemas: `bundle.schema.json`, `student-portal.schema.json`, `bi.schema.json`.
- La directiva nunca recibe datos a nivel estudiante individual.
